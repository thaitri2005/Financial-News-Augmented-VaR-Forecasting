# M1-03 retained market-source contract

The private September 2026 FRED/Cboe snapshots remain the raw evidence. Import them only after SHA-256 and byte/row-count checks against `docs/research/retained_sample_audit.json`. No refresh of FRED's rolling window or Cboe's revised current history is a routine replay. A new source file becomes a new vintage/dataset version, with actual retrieval time; old forecasts keep their original inputs.

FRED `SP500`: dated **price-index close** only, decimal-positive finite values. `.` or empty value is a source placeholder, not a zero close. Preserve placeholder dates/counts and do not forward fill. Cboe `VIX_History`: use `DATE` and `CLOSE` as an independently sourced option-implied-volatility control; `OPEN/HIGH/LOW` are original-source fields but are not added to the S&P 500 target. Both parsers reject duplicate dates, malformed dates, nonfinite/nonpositive observed values and schema changes. The source snapshot is a *historical prior-session availability assumption*, not a proven original release vintage.

Reconcile each observed date against the frozen XNYS calendar by **date key**, never file row position. Report index missing sessions, index values on non-session dates, missing VIX on observed index sessions, VIX dates on closed XNYS dates, and dates outside the requested grid separately. Extra VIX rows never manufacture a missing index close or a forecast origin. Calendar edges may refer to source dates outside the requested origin interval; retain source values for future target construction, but report them as outside-grid observations. Price-source disagreement and extraordinary realized returns are investigated only under the blueprint's outcome access rules.

The first importer is a bounded CSV quality/admission layer, not Parquet materialization. It reads small retained files into typed daily maps; the full normalized Parquet/vintage ledger follows when the source/calendar quality gate and substantial-normalization RAM gate pass. Store series ID, original raw SHA/path/retrieval time, parsed source row counts, and availability basis with resulting objects. Output audits report date coverage and status, not 2023–2025 return distributions or backtest scores.

Small synthetic fixture tests precede a full saved-calendar/source reconciliation. Do not classify an unqueried provider interval or a missing index session as a valid zero-return day. M1-04 adds a separate future-label builder after the import gate; M2 adds causal model inputs and baselines.

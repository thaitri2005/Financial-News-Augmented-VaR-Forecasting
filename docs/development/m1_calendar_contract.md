# M1-02 XNYS origin calendar contract

**Source:** `exchange_calendars==4.13.2`, checked against the [official project](https://github.com/gerrymanoim/exchange_calendars) and [NYSE trading-hours page](https://www.nyse.com/trade/hours-calendars). The local package has XNYS coverage from 2006-09-18 to 2027-09-16 as observed in this environment; do not assume that all future dates exist. The requested date interval is inclusive, but only actual XNYS sessions become forecast origins. A previous and next edge session are queried outside that interval for every origin's news window/target.

The calendar supplies scheduled cash-market open and close in UTC. Each origin freezes news 30 minutes before scheduled close and has an issue deadline 15 minutes before close. The prior XNYS session is the latest admissible daily market-input session; the next XNYS session is the target-end session. A news event belongs to `(previous_origin_cutoff, origin_cutoff]`; exact upper cutoff is included and exact lower cutoff excluded. Target is this session's scheduled close to next session's scheduled close; actual index prices and label availability are materialized separately.

Package version, tzdata version, requested interval, profile/margins and every origin's UTC timestamps are part of canonical sorted JSON. Its SHA-256 is the calendar identity. Save to an immutable `data/calendars/<hash>.json` (Git-ignored) with a temporary file and atomic rename. A file with the same hash but different content is a defect. Loading rechecks the hash and temporal invariants. A package, timezone, cutoff or exchange-closure correction produces a new calendar ID and invalidates dependent dataset/forecast versions; it never changes already issued records.

Historical examples reviewed before coding: Thursday 2025-07-03 XNYS early close 13:00 New York / 17:00 UTC, Friday 2025-07-04 holiday and next session Monday 2025-07-07; Thursday 2025-01-09 is not an XNYS session; DST changes the UTC cutoff for a regular session without changing its 15:30 New York definition. The 2025 early-close rule appears in an [official NYSE historical calendar page](https://www.nyse.com/markets/hours-calendars?ecid=psgonsgcgaen1n); the saved package schedule and official exchange notices must be reconciled if they disagree.

The saved schedule contains no prices, return outcomes, headlines, model fit or retrospective regime tags. Test it with bounded session intervals before building a large production grid. FRED/Cboe import and actual label construction are M1-03/04 tasks.
